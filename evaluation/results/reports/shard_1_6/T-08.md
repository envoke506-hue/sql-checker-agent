## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 基类字段必须命名为 version** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 建表模板 > 实体基类必须字段
- 不满足片段：`ver INT NOT NULL DEFAULT 0`
- 问题说明：版本字段被命名为缩写 ver，不符合基类字段 version 的强制要求
- 整改方案：字段重命名为 version，类型保持 INT NOT NULL DEFAULT 0

**2. 字段命名须使用标准术语单词** · 🟡 WARN · 依据：[3] 《数据库规范》- 数据库规范 > 名词术语 > 标准命名单词字典
- 不满足片段：`revision INT NOT NULL DEFAULT 0`
- 问题说明：revision 非标准术语单词，且与 version 语义重复
- 整改方案：删除 revision 字段，版本语义统一由 version 承载
