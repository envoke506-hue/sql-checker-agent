- 所属模块：字段与索引（05_field_and_index.md）

- 期望命中规则：建表规范 · 布尔类型 TINYINT(4)
- 期望级别：ERROR
- 依据切块：chunk_field_and_index_rules

- 检出违规数：2
- 审查综述：表名、基类七字段、主键、引擎与字符集基本合规。存在两处数据类型违规：布尔字段用 BOOLEAN、单字符拆单标记用 BIT(1)，均不符合建表字段类型规范，需改正。

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 布尔类型必须使用 TINYINT(4)** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`is_paid BOOLEAN NOT NULL DEFAULT FALSE`
- 问题说明：布尔字段用 BOOLEAN 会被驱动映射为 TINYINT(1)，应统一 TINYINT(4)
- 整改方案：改为 TINYINT(4) NOT NULL DEFAULT 0，注释标注 0否 1是

**2. 单字符标记必须使用 char(1)** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`is_split BIT(1) NOT NULL DEFAULT 0`
- 问题说明：1 个字符的标记字段不得使用 BIT(1)，应使用 char(1)
- 整改方案：改为 char(1) NOT NULL DEFAULT 'N'，注释 Y或N

### ✅ 修改后的 SQL
```sql
CREATE TABLE `db_order` (
  id          BIGINT UNSIGNED NOT NULL                       COMMENT '主键',
  is_paid     TINYINT(4) NOT NULL DEFAULT 0                   COMMENT '是否已支付，0: 否 1: 是',
  is_split    char(1) NOT NULL DEFAULT 'N'                    COMMENT '是否需要按段拆单(Y或N)',
  version     INT NOT NULL DEFAULT 0                          COMMENT '数据版本',
  deleted     TINYINT(4) UNSIGNED NOT NULL DEFAULT 0          COMMENT '删除标记 0: 未删除 1: 已删除',
  disabled    TINYINT(4) UNSIGNED NOT NULL DEFAULT 0          COMMENT '停用标记 0: 未停用 1: 已停用',
  create_id   BIGINT UNSIGNED NOT NULL                        COMMENT '创建人标识',
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP     COMMENT '创建时间',
  modify_id   BIGINT UNSIGNED NOT NULL                        COMMENT '修改人标识',
  modify_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP     COMMENT '修改时间',
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';
```
