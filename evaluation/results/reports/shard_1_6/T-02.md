## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 1 项）

**1. 本表字段禁止加表名前缀** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`goods_title VARCHAR(64)`
- 问题说明：本表字段 goods_title 加了表名前缀 goods_，违反本表字段不加表名
- 整改方案：去掉 goods_ 前缀，原 title 改为 name

CREATE TABLE `db_goods` (
  `id` BIGINT UNSIGNED NOT NULL COMMENT '主键',
  `name` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '商品名称',
  `title` VARCHAR(64) NOT NULL DEFAULT '' COMMENT '商品标题',
  `version` INT NOT NULL DEFAULT 0 COMMENT '数据版本',
  `deleted` TINYINT(4) UNSIGNED NOT NULL DEFAULT 0 COMMENT '删除标记 0: 未删除 1: 已删除',
