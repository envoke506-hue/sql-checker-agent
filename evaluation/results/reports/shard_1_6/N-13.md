- 审查综述：表结构基本符合基类字段、引擎与字符集要求，主要问题集中在排序类字段命名：sortIndex 使用驼峰命名，且 seq、sort_no、sortIndex 三者语义重复，应按规范统一为 sort。

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 字段命名必须使用 lower_snake_case** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`sortIndex INT NOT NULL DEFAULT 0`
- 问题说明：sortIndex 为驼峰命名，违反 lower_snake_case 命名规范
- 整改方案：改名为 sort_index

**2. 排序字段统一命名 sort** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 名词术语 > 标准命名单词字典
- 不满足片段：`seq, sort_no, sortIndex`
- 问题说明：三个排序字段语义重复且未使用规范命名 sort
- 整改方案：合并为 sort INT NOT NULL DEFAULT 0
