# T-01 · 主键未使用推荐词 `id`

- 案例类型：反例
- 所属模块：名词术语（02_terminology.md）
- 违反条款：名词术语 > 常用单词 —— 主键：`id`；建表规范 —— 主键（雪花）：`id BIGINT UNSIGNED NOT NULL`
- 期望命中规则：名词术语 · 主键命名
- 期望级别：ERROR
- 依据切块：chunk_terminology
- 执行状态：ok（耗时 48.16s，开始于 2026-10-16T15:13:39+08:00）

- 审查判定：不合规
- 合规得分：40
- 检出违规数：3
- 审查综述：该 DDL 存在主键命名、业务字段前缀和 UNSIGNED 缺失违规，需按规范重构主键与业务字段并补充无符号属性。

## 实测检出明细

| 序号 | rule_name | 级别 | 目标对象 | 引用编号 |

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 3 项）

**1. 主键字段命名必须为 id** · 🔴 ERROR · 依据：[4] 《数据库规范》- 数据库规范 > 建表模板 > 实体基类必须字段
- 不满足片段：`pk_id BIGINT UNSIGNED ... PRIMARY KEY`
- 问题说明：主键字段名为 pk_id，不符合规范主键必须为 id 的要求
- 整改方案：将 pk_id 改为 id，并更新 PRIMARY KEY

**2. 业务字段必须使用 biz_ 前缀** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`sid BIGINT UNSIGNED`
- 问题说明：业务主键字段 sid 未使用 biz_ 前缀，命名不规范
- 整改方案：改为 biz_id BIGINT UNSIGNED

**3. 非负数字必须加 UNSIGNED** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 建表规范 > 建库规范
- 不满足片段：`version INT`
- 问题说明：version 为非负整数但未加 UNSIGNED，不符合数字类型规范
- 整改方案：改为 INT UNSIGNED NOT NULL DEFAULT 0

### ✅ 修改后的 SQL
```sql
CREATE TABLE `db_order` (
  `id` BIGINT UNSIGNED NOT NULL COMMENT '主键',
  `biz_id` BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '业务主键',
  `version` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '数据版本',
  `deleted` TINYINT(4) UNSIGNED NOT NULL DEFAULT 0 COMMENT '删除标记 0: 未删除 1: 已删除',
  `disabled` TINYINT(4) UNSIGNED NOT NULL DEFAULT 0 COMMENT '停用标记 0: 未停用 1: 已停用',
  `create_id` BIGINT UNSIGNED NOT NULL COMMENT '创建人标识',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `modify_id` BIGINT UNSIGNED NOT NULL COMMENT '修改人标识',
  `modify_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '修改时间',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';
```
