## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 3 项）

**1. 本表字段禁止加表名前缀** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`order_money`
- 问题说明：字段名包含本表名 order，作为本表字段应直接使用 money
- 整改方案：重命名为 money，保留 _money 金额后缀

**2. 主键必须包含注释** · 🔴 ERROR · 依据：[2] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`id`
- 问题说明：主键 id 缺少 COMMENT 主键，不符合建表模板
- 整改方案：增加 COMMENT '主键'

**3. 基类字段必须包含中文注释** · 🔴 ERROR · 依据：[3] 《数据库规范》- 数据库规范 > 建表模板 > 实体基类必须字段
- 不满足片段：`version,deleted,disabled,create_id,create_time,modify_id,modify_time`
- 问题说明：7 个通用基类字段缺少中文 COMMENT，未按模板定义
- 整改方案：为各基类字段补充对应中文注释

  id BIGINT UNSIGNED NOT NULL COMMENT '主键',
