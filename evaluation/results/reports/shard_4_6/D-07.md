# D-07 · 字符集使用 `utf8` 而非 `utf8mb4`

- 案例类型：反例
- 所属模块：建库规范（04_database_rules.md）
- 违反条款：建库规范 5 —— 字符集为 `utf8mb4`；第 15 条 —— 建表结尾填了就必须是规范字符集
- 期望命中规则：建库规范 · 字符集必须 utf8mb4
- 期望级别：ERROR
- 依据切块：chunk_database_rules
- 执行状态：ok（耗时 37.69s，开始于 2026-10-16T15:18:27+08:00）

- 审查判定：不合规
- 合规得分：80
- 检出违规数：1
- 审查综述：审查发现 2 项违规：建表字符集 utf8 不符合 utf8mb4 要求，version 字段缺少 UNSIGNED。其余字段符合基类模板与命名规范。

## 实测检出明细

| 序号 | rule_name | 级别 | 目标对象 | 引用编号 |
| --- | --- | --- | --- | --- |
| 1 | 非负数字类型必须加 UNSIGNED | ERROR | version INT NOT NULL DEFAULT 0 | [5] |

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 1 项）

**1. 非负数字类型必须加 UNSIGNED** · 🔴 ERROR · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 建库规范
- 不满足片段：`version INT NOT NULL DEFAULT 0`
- 问题说明：version 为非负数字但未加 UNSIGNED，不符合数字类型规范
- 整改方案：加 UNSIGNED

### ✅ 修改后的 SQL
```sql
CREATE TABLE `db_order` (
  id          BIGINT UNSIGNED NOT NULL                       COMMENT '主键',
  code        VARCHAR(64) NOT NULL DEFAULT ''                COMMENT '订单编号',
  version     INT UNSIGNED NOT NULL DEFAULT 0                COMMENT '数据版本',
  deleted     TINYINT(4) UNSIGNED NOT NULL DEFAULT 0         COMMENT '删除标记 0: 未删除 1: 已删除',
  disabled    TINYINT(4) UNSIGNED NOT NULL DEFAULT 0         COMMENT '停用标记 0: 未停用 1: 已停用',
  create_id   BIGINT UNSIGNED NOT NULL                       COMMENT '创建人标识',
  create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP    COMMENT '创建时间',
  modify_id   BIGINT UNSIGNED NOT NULL                       COMMENT '修改人标识',
  modify_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP    COMMENT '修改时间',
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';
```
