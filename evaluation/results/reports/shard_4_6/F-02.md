## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 本表字段禁止加表名前缀且编号应使用 code** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`third_order_no`
- 问题说明：本表字段加了表名前缀，且编号后缀应为 code
- 整改方案：改为 code VARCHAR(64)，去掉表名前缀

**2. 三方对接表需包含系统来源和数据来源** · 🔴 ERROR · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`db_third_order`
- 问题说明：与三方对接的表缺少 data_source 字段
- 整改方案：增加 data_source VARCHAR(64) 默认空串

  `id` BIGINT UNSIGNED NOT NULL COMMENT '主键',
