### ⚠️ 不满足项与整改方案（共 3 项）

**1. 本表字段禁止拼接本表表名** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`third_order_no`
- 问题说明：字段名拼接本表表名 third_order，违反本表字段不加表名原则
- 整改方案：改名为 order_code，去掉 third_order 前缀

**2. 编号编码字段命名后缀为 code** · 🟡 WARN · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`third_order_no`
- 问题说明：编号类字段命名后缀应为 code，no 不符合命名规范
- 整改方案：字段名改为 order_code

**3. 三方对接表必须包含系统来源与数据来源** · 🔴 ERROR · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`system_source`
- 问题说明：与三方对接表缺少 system_source 系统来源字段
- 整改方案：增加 system_source 字段，用于区分对方系统

CREATE TABLE `db_third_order` (
  id            BIGINT UNSIGNED NOT NULL                   COMMENT '主键',

  system_source VARCHAR(64) NOT NULL DEFAULT ''             COMMENT '系统来源（对方系统）',
  data_source   VARCHAR(64) NOT NULL DEFAULT ''             COMMENT '数据来源（对方机构）',
