- 案例类型：反例
- 所属模块：建表模板（03_table_template.md）
- 违反条款：建表模板 —— 主键必须为 `id BIGINT UNSIGNED NOT NULL`
- 期望命中规则：建表模板 · 主键必须为 id
- 期望级别：ERROR
- 依据切块：chunk_table_template、chunk_field_and_index_rules
- 执行状态：ok（耗时 23.87s，开始于 2026-10-16T15:15:34+08:00）

- 审查判定：不合规
- 合规得分：60

- 审查综述：DDL 主要违规是主键字段 order_id 带本表表名前缀且未统一命名为 id；其余基类字段、InnoDB、utf8mb4 和注释基本符合规范。

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 本表字段禁止加表名** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`order_id`
- 问题说明：主键字段 order_id 加了本表表名前缀，违反本表字段不加表名规则
- 整改方案：主键改为 id BIGINT UNSIGNED NOT NULL

**2. 主键必须命名为 id** · 🔴 ERROR · 依据：[3] 《数据库规范》- 数据库规范 > 建表模板 > 实体基类必须字段
- 不满足片段：`PRIMARY KEY (order_id)`
- 问题说明：主键字段未使用规范名 id，违反实体基类模板要求
- 整改方案：PRIMARY KEY 改为 PRIMARY KEY (id)
