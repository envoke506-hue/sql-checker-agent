# T-06 · 审核与标识未使用推荐词 `audit` / `tag`

- 案例类型：反例
- 所属模块：名词术语（02_terminology.md）
- 违反条款：名词术语 > 常用单词 —— 审核：`audit`，标识：`tag`
- 期望命中规则：名词术语 · 审核/标识命名
- 期望级别：WARN
- 依据切块：chunk_terminology
- 执行状态：ok（耗时 34.6s，开始于 2026-10-16T15:14:05+08:00）

- 审查判定：不合规
- 合规得分：80
- 检出违规数：1
- 审查综述：审查发现 3 处命名违规：mark_no 未用 _code 后缀，review、check_flag 未使用标准术语。基类字段、类型、引擎字符集均符合规范。

## 实测检出明细

| 序号 | rule_name | 级别 | 目标对象 | 引用编号 |
| --- | --- | --- | --- | --- |
| 1 | 编号编码命名后缀必须为 _code | ERROR | mark_no VARCHAR(32) | [1] |

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 1 项）

**1. 编号编码命名后缀必须为 _code** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`mark_no VARCHAR(32)`
- 问题说明：字段 mark_no 未使用编码后缀 _code，违反命名规范
- 整改方案：改为 tag_code VARCHAR(32)

CREATE TABLE `db_apply` (
  id          BIGINT UNSIGNED NOT NULL                       COMMENT '主键',
  audit_status TINYINT(4) UNSIGNED NOT NULL DEFAULT 0        COMMENT '审核状态',
  audit_tag   TINYINT(4) UNSIGNED NOT NULL DEFAULT 0         COMMENT '审核标记',
  tag_code    VARCHAR(32) NOT NULL DEFAULT ''                COMMENT '标识编码',
  version     INT NOT NULL DEFAULT 0                         COMMENT '数据版本',
