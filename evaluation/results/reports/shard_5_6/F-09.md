# F-09 · 大于 1 个字符的字段使用 `TEXT` 且无默认值

- 案例类型：反例
- 所属模块：字段与索引（05_field_and_index.md）
- 违反条款：建表规范 7 —— 大于 1 个字符使用 `varchar(30) NOT NULL DEFAULT ''`
- 期望命中规则：建表规范 · 大于1字符用 varchar
- 期望级别：ERROR
- 依据切块：chunk_field_and_index_rules
- 执行状态：ok（耗时 57.86s，开始于 2026-10-16T15:17:49+08:00）

- 审查判定：不合规
- 合规得分：50
- 检出违规数：3
- 审查综述：发现字段命名含表名前缀、车牌号使用 TEXT 且缺少默认值、司机姓名缺少默认空串，需按规范调整。

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 3 项）

**1. 本表字段禁止加表名前缀** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`vehicle_number`
- 问题说明：vehicle_number 含表名 vehicle_，本表字段不应加表名前缀
- 整改方案：改为 number

**2. 字符串应使用 varchar(30)** · 🔴 ERROR · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`vehicle_number TEXT NOT NULL`
- 问题说明：车牌号 TEXT 无默认值，应改用 varchar(30)
- 整改方案：改为 varchar(30) NOT NULL DEFAULT ''

**3. 大于1个字符应默认空串** · 🟡 WARN · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 字段设计与索引命名
- 不满足片段：`driver_name VARCHAR(30) NOT NULL`
- 问题说明：driver_name 缺少 DEFAULT ''，不符合字符串字段规范
- 整改方案：增加 DEFAULT ''

### ✅ 修改后的 SQL
```sql
CREATE TABLE `db_vehicle` (
  `id` BIGINT UNSIGNED NOT NULL COMMENT '主键',
  `number` VARCHAR(30) NOT NULL DEFAULT '' COMMENT '车牌号',
  `driver_name` VARCHAR(30) NOT NULL DEFAULT '' COMMENT '司机姓名',
  `version` INT NOT NULL DEFAULT 0 COMMENT '数据版本',
  `deleted` TINYINT(4) UNSIGNED NOT NULL DEFAULT 0 COMMENT '删除标记 0: 未删除 1: 已删除',
  `disabled` TINYINT(4) UNSIGNED NOT NULL DEFAULT 0 COMMENT '停用标记 0: 未停用 1: 已停用',
  `create_id` BIGINT UNSIGNED NOT NULL COMMENT '创建人标识',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `modify_id` BIGINT UNSIGNED NOT NULL COMMENT '修改人标识',
  `modify_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '修改时间',
```
