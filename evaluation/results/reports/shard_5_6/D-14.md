# D-14 · 使用 `double` 存储金额

- 案例类型：反例
- 所属模块：建库规范（04_database_rules.md）
- 违反条款：建库规范 12 —— `double` 类型不要用，直接用 `decimal`；命名规范 17 —— 金额统一 `decimal(20, 6)`
- 期望命中规则：建库规范 · 禁用 double
- 期望级别：ERROR
- 依据切块：chunk_database_rules
- 执行状态：ok（耗时 38.71s，开始于 2026-10-16T15:16:58+08:00）

- 审查判定：不合规
- 合规得分：60
- 检出违规数：2
- 审查综述：发现 2 处违规：支付金额 pay_money 与费率 fee_rate 使用 DOUBLE，存在精度风险，应改为 DECIMAL；其余基类字段、主键、引擎、字符集和表注释符合规范。

## 实测检出明细

| 序号 | rule_name | 级别 | 目标对象 | 引用编号 |
| --- | --- | --- | --- | --- |
| 1 | 金额字段必须使用 decimal(20,6) | ERROR | pay_money DOUBLE NOT NULL DEFAULT 0 | [1] |
| 2 | 禁止使用 double 类型 | ERROR | fee_rate DOUBLE NOT NULL DEFAULT 0 | [5] |

## 整改回复 (markdown_report)

### ⚠️ 不满足项与整改方案（共 2 项）

**1. 金额字段必须使用 decimal(20,6)** · 🔴 ERROR · 依据：[1] 《数据库规范》- 数据库规范 > 命名规范 > 规则清单与反例
- 不满足片段：`pay_money DOUBLE NOT NULL DEFAULT 0`
- 问题说明：pay_money 为金额字段却使用 double，未按要求用 decimal(20,6)
- 整改方案：改为 decimal(20, 6)，保留 _money 后缀

**2. 禁止使用 double 类型** · 🔴 ERROR · 依据：[5] 《数据库规范》- 数据库规范 > 建表规范 > 建库规范
- 不满足片段：`fee_rate DOUBLE NOT NULL DEFAULT 0`
- 问题说明：fee_rate 使用 double 类型，违反禁止使用 double 的规范
- 整改方案：改为 decimal(20, 6)
